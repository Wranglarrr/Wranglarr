Changing it

The apps' logins are set when the stack is set up, not from here. In the stack's folder:

  1. Pick the new setup in the setup wizard, Logins only (it changes nothing else in .env), then open http://localhost:8788: 
    {{ rerun[0] }}
  2. Apply it. This sets each app's login and, for AuthTunnel, starts or removes wranglarr-gate: 
    {{ rerun[1] }}

The three ways and their trade-offs: wiki, App Logins.
