No containers are managed: set container = "…" on the apps in wranglarr.toml.

Save a tag to select its update track, or leave it blank to follow the deployed image. Suggestions come from the image publisher; a custom tag works for any repository. Saving does not restart a container: press Check now, then Update. Scheduled updates also follow the saved track. Development tracks may migrate databases; returning to an older track can require a backup restore. Wranglarr's own row follows its track when you press Update now.

Checks ask the registry for the current digest of each tag without pulling anything. An update backs up the affected suite first (Postgres updates back up every suite with databases), pulls the image, then recreates the container with its exact mounts, environment, networks and labels. If the new container isn't healthy within the timeout the old one is put back. Apps sharing the VPN container's network are recreated with it.
