Import a config

A config holds the arr settings for one job (custom formats, quality profiles and sizes, release and delay profiles, auto tagging, tags, naming), like "x265 up to 1080p" or "anime with an English dub". Paste one someone shared, or a custom format from an arr's Export button or TRaSH Guides. wranglarr shows what would change before anything is saved, and every import can be removed again.

Examples:

Installed

Each app's settings over time, newest first: every config installed, and the changes wranglarr noticed made in the app by hand. Removing a config replays the rest without it. When later changes touch the same settings, you pick whether they stay as they are, or the config comes out throughout.

Test a release name

Asks the arr how it reads a release name: its quality, the custom formats it matches, and the score each quality profile gives it.

Export a config

Pick the settings that belong to the job. Picks from several apps go into one config. Everything goes in by name: ids, paths and anything else tied to this server are left out.

New names:
PickedName in the configImport
A config that reuses a name the arrs ship with (HD-1080p, Any…) changes that profile wherever it's imported, unless the importer takes a copy. A name of its own avoids that. What points at a renamed item follows it.
